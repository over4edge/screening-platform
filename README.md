# SoundScreen · 人力筛选平台

音乐 / 音效 / AI审美 听辨筛选的任务大厅与管理后台。

## 架构
- **前端**：本仓库（GitHub Pages 静态托管），仅 UI，不含题库与答案
- **后端**：腾讯云 SCF（函数 URL），负责抽题、判分、答卷存储、飞书汇总与通知
- **媒体**：腾讯云 COS 公有桶（音频由后端 API 下发 URL）

## 页面
- `index.html` 任务大厅
- `admin.html` 管理后台（登录后管理任务/批改/账号）
- `exam.html?task=<id>` 考试页
- `review.html?c=<code>` 答卷审核页

## 说明
前端不持有答案与判分逻辑；所有安全逻辑（题库、判分、鉴权）在服务端。
